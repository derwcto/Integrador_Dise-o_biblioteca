📖 Flujo de préstamo

  1. Registra libros desde Mantenimiento de Libros.
  2. Ve a Préstamos y Devoluciones y selecciona lector y libro.
  3. El sistema llama a sp_RegistrarPrestamo (valida lector activo y stock, descuenta existencias).
  4. Al devolver, la multa se calcula con fn_CalcularMultaPorRetraso y el stock se repone.

🛠️ Requisitos de base de datos

  • Base de datos biblioteca en MySQL (localhost).
  • Tablas Libros, Lectores, Prestamos, Detalle_Prestamos.
  • Procedimiento sp_RegistrarPrestamo y función fn_CalcularMultaPorRetraso.
  • Si no existen, ejecuta python apply_schema.py incluido en el proyecto.
